# 书面作业

课程设置一次数学基础诊断和四次正式书面作业。HW0 用于检查学习本课程所需的数学基础；HW1–HW4 均为单人完成，覆盖对应阶段的核心概念、推导和分析。

正式书面作业以人工批改为主。每次作业最多包含一道适度超过课堂范围的拓展题，题目会给出必要背景，使其仍可从本次作业的课内知识出发完成。

## 已发布内容

### HW0 数学基础诊断

检查线性代数、多元微积分、概率统计和基础优化知识。HW0 的作用是帮助同学发现薄弱环节并及时复习，不作为正式书面作业难度的参照。
