# 书面作业

课程设置一次数学基础诊断和四次正式书面作业。HW0 用于检查学习本课程所需的数学基础；HW1–HW4 均为单人完成，覆盖对应阶段的核心概念、推导和分析。

正式书面作业以人工批改为主。每次作业最多包含一道适度超过课堂范围的拓展题，题目会给出必要背景，使其仍可从本次作业的课内知识出发完成。

## 内容说明

### HW0 数学基础诊断

检查线性代数、多元微积分、概率统计和基础优化知识。HW0 的作用是帮助同学发现薄弱环节并及时复习，不作为正式书面作业难度的参照。

### HW1 线性模型、评估与泛化

围绕一个完整的监督学习流程，讨论线性回归的解析解与梯度方法、训练/验证/测试数据的作用、常用回归与分类指标、正则化的偏差—方差权衡，以及逻辑回归和交叉熵。

拓展内容可涉及稀疏正则化、鲁棒损失或正则化路径。

### HW2 神经网络与反向传播

从张量形状和前馈计算出发，分析多层感知机、激活函数、Softmax 与交叉熵，并在计算图上推导反向传播。作业同时关注初始化、梯度消失或爆炸以及数值梯度检查。

拓展内容可涉及残差连接、自动微分或 Jacobian-vector product。

### HW3 无监督学习与表示学习

讨论 K-means 的目标与迭代过程、聚类初始化和评价方法、GMM 的概率建模、EM 的 E/M 两步，以及 PCA 的方差最大化、特征分解与重构误差解释。

拓展内容可涉及 Kernel PCA、谱聚类或简化的变分推断。

### HW4 非线性监督学习与搜索

讨论 SVM 的最大间隔、对偶问题和核技巧，决策树的划分准则与剪枝，Bagging、随机森林和 Boosting 的差异，并引入 Uniform-Cost Search、A* 与启发函数的正确性条件。

拓展内容可涉及 Boosting 的 margin 解释或 MCTS/UCT，为期末多人实验建立联系。
